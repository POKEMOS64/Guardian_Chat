# Руководство по участию в разработке (Contributing)

Привет! Мы рады, что вы хотите помочь развитию проекта **Guardian Chat**.

Это руководство поможет вам понять, как вы можете внести свой вклад.

## 🤝 Как можно помочь?

### 1. Сообщение об ошибках (Bug Reports)
Если вы нашли ошибку, пожалуйста, создайте Issue в репозитории.
*   **Используйте поиск**, чтобы проверить, не сообщал ли кто-то об этой ошибке ранее.
*   Опишите шаги для воспроизведения ошибки.
*   Укажите ваше окружение (ОС, браузер, версия Node.js).

### 2. Предложение улучшений (Feature Requests)
У вас есть идея, как сделать чат лучше?
*   Создайте Issue с меткой `enhancement`.
*   Опишите, какую проблему решает ваше предложение.
*   Если возможно, приложите макеты или примеры.

### 3. Отправка кода (Pull Requests)
Мы приветствуем Pull Request'ы (PR) с исправлениями и новыми функциями.

1.  **Форкните репозиторий** и клонируйте его себе.
2.  Создайте ветку для ваших изменений:
    ```bash
    git checkout -b feature/my-new-feature
    ```
3.  **Следуйте стилю кода**:
    *   Используйте CommonJS (`require`).
    *   Пишите понятные комментарии.
    *   Соблюдайте существующую структуру проекта.
4.  Протестируйте изменения локально.
5.  Закоммитьте изменения с понятным сообщением:
    ```bash
    git commit -m "Добавлена функция предпросмотра ссылок"
    ```
6.  Сделайте Push в ваш форк и откройте Pull Request в основной репозиторий.
